| 모듈      | 사용할 API                                                     |
| ------- | ----------------------------------------------------------- |
| Button  | `button.pressed`, `button.clicked`, `button.double_clicked` |
| Dial    | `dial.turn`, `dial.speed`                                   |
| Env     | `env.temperature`, `env.humidity`                           |
| TOF     | `tof.distance`                                              |
| LED     | `led.rgb = (r,g,b)` 또는 `led.set_rgb()`                      |
| Display | `display.text = "..."` 또는 `display.write_text()`            |
| Speaker | `speaker.set_tune()` 또는 `speaker.tune`                      |
